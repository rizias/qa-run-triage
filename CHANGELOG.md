# История изменений

Все заметные изменения проекта документируются в этом файле. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), нумерация версий — на
[семантическом версионировании](https://semver.org/lang/ru/).

## [Не выпущено]

### Добавлено

- Команды для Jenkins: список джоб и прогонов, скачивание прогона, сводка, падения, поиск повторов ошибки.
- Код упавшего теста Java или Playwright из исходников прогона или из локального клона по коммиту.
- Журнал разборов: зелёные прогоны записываются сами, вердикт по красным записывает агент.
- HTML-отчёт по журналу: состояние джоб, история, повторяемость ошибок, вердикты.
- Профили настроек с секретами в отдельном файле; несколько серверов CI в одном профиле.
- Режимы аутентификации сервера: без входа, логин и пароль, API-токен Jenkins.
- Ограничение доступа списком разрешённых джоб; числовые пределы кэша, отчёта и ожиданий.
- Скилл разбора в пакете: команда `init` ставит его агентам, `update` обновляет пакет.

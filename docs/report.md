# HTML-отчёт

Отчёт строится только из журнала и показывает:

- состояние джоб, последние прогоны и открытые проблемы за выбранное окно;
- историю каждой джобы по окружениям, результаты, числа упавших и восстановившихся тестов,
  подписи ошибок и вердикты;
- повторяемость точных текстов ошибок, первое и последнее появление, статус по сочетанию
  «сервер + джоба + окружение»; страницы и ссылки различают одинаковые джобы разных серверов;
- архив прогонов по месяцам, число неполных записей и строк журнала, которые не удалось разобрать.

Соберите отчёт и откройте его входной HTML-файл в браузере:

```bash
qa-run-triage report
```

По умолчанию файл находится в `<cacheDir>/journal-report/index.html`. Другой каталог и длина
окна главной страницы задаются так:

```bash
qa-run-triage report --out-dir /path/to/qa-report --window-days 30
```

Даты, время и месяцы архива используют `report.timeZone` выбранного профиля или переменную
`QA_RUN_TRIAGE_REPORT_TIME_ZONE`. По умолчанию действует пояс машины сборки. Подпись
смещения относительно UTC вычисляется для этого пояса на момент сборки. Пояс сохраняется
в данных поколения, поэтому системный пояс браузера не меняет отображение.

Каждая сборка создаёт новое поколение и переключает `index.html` на него, не удаляя предыдущие.
